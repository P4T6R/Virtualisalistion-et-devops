# Mesures brutes

La campagne VirtualBox a été exécutée le 18 octobre 2026. Ce dossier contient
les fichiers JSON, CSV et ApacheBench horodatés utilisés par la matrice de
validation et le rapport d'architecture.

Les essais intermédiaires infructueux sont conservés. Ils documentent le conflit
d'adresses, le premier défaut de basculement et la sonde E4 qui s'est arrêtée
avant la fin du déploiement. Les preuves finales à présenter sont listées dans
docs/VALIDATION.md.

Ces fichiers sont ignorés par Git parce qu'ils représentent des mesures locales.
Ils sont inclus explicitement dans l'archive finale. Aucun mot de passe généré,
fichier .env ou fichier .runtime n'y est ajouté.
